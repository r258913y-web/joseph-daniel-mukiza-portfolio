# Joseph Daniel Mukiza — Portfolio

A responsive, creative-gradient portfolio for a technopreneur and web developer.

## Included
- Responsive design for desktop, tablet, and mobile
- About section and entrepreneurship values
- Skills: HTML, CSS, JavaScript, Bootstrap, React, Python, SQL, Supabase
- Project concepts clearly labelled as concepts/in progress
- Contact link using the supplied public email
- Mobile navigation and reduced-motion support

## Run locally
Open `index.html` in any modern browser. No build step or package installation is required.

## Customize
- Replace the project concepts in `index.html` with real projects, demos, source links, and outcomes.
- Adjust colours and responsive styles in `style.css`.
- Update the contact address if needed.
